# Analise-de-Incidente-e-Engenharia-Social-Vero
Análise de Incidente e Engenharia Social: Vetor de Ataque via APK Malicioso e Spoofing de Atendimento (Trojan Bancário/RAT)

Este repositório documenta a análise técnica, investigação OSINT e resposta a um incidente de segurança cibernética ocorrido em setembro de 2026. A abordagem envolveu um vetor de Engenharia Social altamente direcionada via WhatsApp, utilizando informações contextuais de um atendimento prévio com um provedor de internet (Vero), culminando na tentativa de infecção por um Trojan de Acesso Remoto (RAT) Android via arquivo .apk sideloaded.
